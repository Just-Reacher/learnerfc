# ⚽ Learners FC Website

This is the official website project for **Learners FC**, a football team being built from scratch. The website is designed to establish the club's digital identity and document its growth over time — from its earliest days as a project, through its first sessions, squads, and matches.

---

## About Learners FC

Learners FC's name is not just a label — it's a philosophy.

### LEARN
We learn the fundamentals of football and life.

### RELEARN
We relearn consistency, humility, and hard work.

### UNLEARN
We unlearn fear, excuses, and complacency.

Learners FC believes football development should involve both football ability and personal character. Together, we are preparing the next generation to be ready for anything.

> **This is how we build players.**

---

## About the Website

The website serves as the digital home of Learners FC. It is designed to showcase:

- Club identity
- Club philosophy
- Players
- Coaching staff
- Fixtures and results
- News
- Media
- Player development
- Contact information

The site is intentionally designed to grow alongside the football club — as the club evolves, so will the website.

- **`index.html`** — the homepage and entry point of the website.

- **`README.md`** — this documentation file.

## Running the Website Locally

This is currently a static website and does not require a database or backend server.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

For development, using a local development server such as **VS Code Live Server** is recommended for a smoother experience with relative paths and live reloading.

## Design Philosophy

The website is designed around **Football + Development + Character**.

The goal is not simply to display a football team, but to communicate what Learners FC stands for.

> **We don't just develop footballers. We prepare people for life.**

---

## Project Vision

Learners FC is being built from scratch, and this website is intended to grow alongside the club as it takes shape. Future milestones the site may one day document include:

- First training sessions
- First squad
- First competitive match
- First goal
- First victory
- First tournament
- First trophy

None of these milestones have occurred yet. This README describes the club's intended direction, not its history. Over time, the website is intended to become a digital archive of the club's journey — from its very first steps to whatever comes next.
